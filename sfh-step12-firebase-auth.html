Create an account or sign in. This page uses Firebase Authentication when your Firebase Web App config is connected.

Setup checklist

  1. Create/register a Firebase Web App.
  2. Copy its Web App config into firebase-config.js.
  3. Enable Authentication → Email/Password.
  4. Create Firestore Database in production mode.
  5. Apply the project’s Firestore security rules before using real customer orders.
Never add a Firebase Admin SDK private key to this public GitHub repository.
