🔥 Santosh Fashion Hub — Real Online Database Setup

Step 11 prepares Firebase Authentication + Cloud Firestore. The website can stay in local mode until your Firebase project configuration is added.

One-time Firebase setup

1
Open Firebase Console and create a project such as Santosh Fashion Hub.
2
Register a Web app in Project settings. Firebase gives you a Web App configuration object.
3
Enable Authentication → Sign-in method → Anonymous for customer checkout, and Email/Password for the store admin.
4
Create Cloud Firestore database in production mode and publish the rules from firestore.rules in this repository.
5
Open firebase-config.js in this GitHub repo and replace the placeholder values with your Web App config.

Firebase Web config format

window.SFH_FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "...firebaseapp.com",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
Security: Do not paste a Firebase Admin SDK private key or service-account JSON into the website. Firestore access must be protected by Authentication and Security Rules. Firebase documents that web clients should use Authentication with Firestore Security Rules for user-based access control.

What becomes live after configuration?

Customer checkout will create a central orders document, using anonymous authentication. The store admin account can be granted access to all orders by the email rule in firestore.rules.
