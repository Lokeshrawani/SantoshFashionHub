# Santosh Fashion Point – Online Store

A modern, mobile-friendly ecommerce-style storefront inspired by current Indian shopping UX patterns.

## Included
- Responsive homepage
- Category browsing
- Product search
- Product cards with IDs and prices
- Simple cart
- WhatsApp order flow
- Shop photos supplied by the owner
- Contact section
- Mobile-friendly design

## Important
The WhatsApp number has been configured as `9835567894`.

## Run
Open `index.html` in a browser, or use VS Code + Live Server.

## Before real launch
1. Replace sample product prices with your actual prices.
2. Add real product photos in `assets/`.
3. Add size/colour/stock fields.
4. Connect a real payment gateway (UPI/card).
5. Connect shipping/courier and COD.
6. Add GST/business/legal information as applicable.
7. Use a real domain and HTTPS.
8. Add privacy policy, terms, shipping and return policy.
