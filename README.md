# Santosh Fashion Hub — Advanced Online Store

Modern, mobile-first static storefront for **Santosh Fashion Hub — Fashion for Everyone**.

## Included
- Responsive Flipkart/Meesho-inspired storefront layout
- Product search, category filters and sorting
- Product quick-view with size selection
- Cart with quantity controls and localStorage persistence
- Wishlist with localStorage persistence
- Demo coupon support (`WELCOME10`)
- WhatsApp cart checkout and enquiry form
- Shop photos
- Mobile bottom navigation
- FAQ and store information
- PWA-ready theme metadata

## Important
The catalog prices are **sample/demo prices**. Update `products` in `script.js` with your actual inventory, prices, sizes and stock.

This GitHub Pages version is frontend-only. Real online payments, customer accounts, secure admin management, inventory synchronization, order database, courier APIs and automated order status require a backend and payment/shipping integrations.
