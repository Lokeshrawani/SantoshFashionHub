One-time Firebase setup

1
Firebase Console → Authentication → Sign-in method → enable Email/Password.
2
Firebase Console → Firestore Database → Create database.
3
Copy your Firebase Web App config into firebase-config.js. Do not add a service-account private key.
4
Publish the repository's firestore.rules using Firebase Console or Firebase CLI.
Current repository state: the public firebase-config.js file still contains placeholders, so the central online database is not active until you add your own Web App config.
